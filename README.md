# Sistema de login em PHP

**IFAC · Técnico em Informática para Internet (TIPI)** · 2022

Cadastro e login de usuários em PHP com sessão e MySQL. Os forks [Complete-Login-System-in-PHP](https://github.com/itskelme/Complete-Login-System-in-PHP) e [Sistema-de-login-com-PHP-e-MySQL](https://github.com/itskelme/Sistema-de-login-com-PHP-e-MySQL) serviram de referência.

| Arquivo | |
|---|---|
| `index.php` | Login |
| `cadastro.php` | Cadastro de usuário |
| `header.php`, `footer.php`, `style.css` | Layout |

```bash
php -S localhost:8000
```
